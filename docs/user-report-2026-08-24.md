# ERP 매출 분석 챗봇 사용자용 보고서

- 보고일: 2026-08-24
- 보고 대상: ERP 매출 분석 챗봇 사용자

## 1. 서비스 소개

ERP에 저장된 매출 데이터를 자연어로 질문하고, 결과를 표와 차트로 확인할 수 있는 웹 기반 매출 분석 챗봇입니다.

복잡한 검색 조건이나 별도의 SQL 작성 없이 평소 업무에서 사용하는 문장으로 매출 현황을 조회할 수 있습니다.

## 2. 제공 기능

### 매출 데이터 질문

다음과 같은 방식으로 질문할 수 있습니다.

- 기간별 매출 현황
- 상품별 또는 거래처별 매출
- 매출 상위 항목
- 전월 대비 순위 변동
- 특정 조건에 해당하는 매출 내역

질문 내용에 따라 AI가 적절한 매출 데이터를 조회해 답변합니다.

### 표와 차트로 확인

조회 결과는 대화형 답변과 표로 표시됩니다. 데이터 성격에 따라 막대 차트 또는 선 차트로도 확인할 수 있습니다.

순위가 오른 항목은 상승 색상, 내려간 항목은 하락 색상으로 표시되어 변동 내용을 쉽게 구분할 수 있습니다.

### PDF 다운로드

조회 결과에 표나 차트가 포함된 경우, 결과를 PDF 파일로 다운로드할 수 있습니다.

PDF는 현재 대화에서 확인된 결과를 기준으로 생성됩니다.

### 이메일 발송

조회 결과를 이메일로 보낼 수 있습니다.

- 여러 명의 수신자에게 한 번에 발송 가능
- 자주 사용하는 수신자는 목록에서 여러 명 선택 가능
- 목록에 없는 주소는 직접 입력 가능
- 여러 주소는 쉼표 또는 세미콜론으로 구분 가능

## 3. 기본 이용 방법

1. 채팅 화면에 궁금한 매출 내용을 문장으로 입력합니다.
2. AI가 매출 데이터를 조회할 때까지 기다립니다.
3. 답변, 표, 차트로 결과를 확인합니다.
4. 필요한 경우 PDF 다운로드 또는 이메일 발송을 선택합니다.
5. 이메일 발송 시 수신자를 선택하거나 직접 입력한 뒤 발송합니다.

## 4. 질문 예시

- `이번 달 매출 상위 10개 상품을 보여줘`
- `최근 3개월 지역별 매출을 비교해줘`
- `지난달보다 순위가 오른 상품을 알려줘`
- `거래처별 매출을 표로 정리해줘`
- `이 결과를 PDF로 저장해줘`

기간, 대상, 정렬 기준, 표시 형식을 구체적으로 입력할수록 원하는 결과를 얻기 쉽습니다.

## 5. 이메일 이용 시 참고사항

- 이메일 주소 형식이 올바른지 확인해야 합니다.
- 회사에서 허용한 이메일 도메인으로만 발송할 수 있습니다.
- 자주 사용하는 수신자 목록은 운영 설정에 등록된 주소만 표시됩니다.
- 목록에 표시된 주소라도 허용되지 않은 도메인이면 발송되지 않을 수 있습니다.
- 이메일 기능은 운영 환경의 메일 서버 설정이 완료된 경우에만 사용할 수 있습니다.

## 6. 데이터 및 보안 안내

- 조회는 승인된 매출 데이터 범위에서만 이루어집니다.
- 시스템은 읽기 전용 방식으로 데이터를 조회하며 원본 데이터를 변경하지 않습니다.
- 실제 데이터 조회가 확인되지 않은 내용은 결과로 확정해 표시하지 않습니다.
- 허용되지 않은 데이터나 이메일 주소에 대한 접근은 차단됩니다.

## 7. 이용에 문제가 있을 때

다음 사항을 먼저 확인해 주세요.

- 질문에 기간과 조회 대상을 포함했는지 확인
- 백엔드와 웹 화면이 정상적으로 실행 중인지 확인
- 이메일 발송 시 수신자 주소와 회사 도메인 확인
- 이메일 기능이 운영 환경에서 활성화되어 있는지 확인

문제가 계속되면 질문 내용, 발생 시각, 화면에 표시된 오류 메시지를 함께 운영 담당자에게 전달해 주세요.

## 8. 현재 제공 상태

매출 자연어 조회, 표·차트 표시, 순위 변동 표시, PDF 다운로드, 다중 수신자 이메일 발송 기능이 구현되어 있습니다.

서비스를 실제로 사용하려면 운영 환경에 매출 데이터베이스, AI 서비스, 필요 시 메일 서버 연결 설정이 완료되어야 합니다.
